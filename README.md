# מטלות הבית 🏠⭐

אפליקציה משפחתית לניהול מטלות הבית: כל ילד בוחר מטלה שבועית, מדווח על ביצוע, ההורה מאשר, הקרדיטים נצברים ובסוף החודש ממירים אותם בחנות.

## קבצים
| קובץ | מה זה |
|---|---|
| `index.html` | כל האפליקציה (קובץ אחד) |
| `schema.sql` | הטבלאות, החוקים וההרשאות ב-Supabase |
| `manifest.json`, `sw.js`, `icon*.png`, `icon.svg` | התקנה כאפליקציה בטלפון (PWA) |

## התקנה (פעם אחת, ~10 דקות)

### 1. Supabase
1. פתחו את הפרויקט **Down-to-the-bone**. כל הטבלאות מתחילות ב-`ch_`, כך שהן לא נוגעות באפליקציות האחרות שם.
2. **SQL Editor → New query** → מדביקים את כל `schema.sql` → **Run**.
3. **Authentication → Sign In / Providers → Email** → לוודא ש-**Confirm email כבוי**. בלי זה ילדים לא יוכלו להיכנס. אם זה כבר כבוי בשביל אפליקציית דמי הכיס, אין מה לשנות.
4. **Project Settings → API** → להעתיק את ה-**Project URL** ואת ה-**anon public key**.

### 2. הגדרת הקובץ
ב-`index.html`, בראש הסקריפט:
```js
const CONFIG = {
  SUPABASE_URL: 'https://xxxx.supabase.co',
  SUPABASE_ANON_KEY: 'eyJ...',
  EMAIL_DOMAIN: 'matalot-bait.app'
};
```
`EMAIL_DOMAIN` הוא רק סיומת פנימית שהופכת שם משתמש לכתובת שהמערכת מקבלת, ואף אחד לא מקבל אליה מייל. אם Supabase דוחה אותה, אפשר להשתמש באותה סיומת שעבדה באפליקציית דמי הכיס.

### 3. GitHub Pages
1. ריפו חדש (למשל `Matalot-bait`) → מעלים את כל הקבצים לתיקייה הראשית.
2. **Settings → Pages → Deploy from branch → main / root**.
3. פותחים את הכתובת בטלפון → "הוספה למסך הבית".

### 4. הפעלה ראשונה
- בכניסה הראשונה מופיע מסך **"הגדרה ראשונה"**, ושם יוצרים את חשבון המנהל. המסך הזה מופיע רק כל עוד אין מנהל.
- בלשונית **ילדים** → "הוספת ילד" → שם, שם משתמש (באנגלית) וסיסמה לכל ילד.
- יש מטלות ופרסים לדוגמה. אפשר לערוך, להסתיר או למחוק אותם.

## איך זה עובד
- **שבוע** = ראשון עד שבת לפי שעון ישראל. כל ילד בוחר מטלה אחת לשבוע ויכול להחליף אותה עד הדיווח הראשון.
- **מטלה** כוללת: קרדיטים לכל ביצוע, כמה פעמים בשבוע אפשר לדווח עליה, האם היא "לילד אחד" (רק ילד אחד בשבוע יכול לבחור אותה), ולאילו ילדים היא מתאימה.
- **דיווח** → נכנס ל"ממתינים" אצל המנהל → אישור (אפשר לשנות את מספר הקרדיטים) או דחייה עם הסבר. רק דיווח מאושר מוסיף ליתרה.
- **חנות**: במצב אוטומטי היא פתוחה ב-X הימים האחרונים של החודש (ברירת מחדל 3). אפשר גם לפתוח או לסגור אותה ידנית. קנייה מורידה קרדיטים מיד, דחייה מחזירה אותם. יתרה שלא נוצלה עוברת לחודש הבא.
- **בונוס/קנס**: מהסקירה, לכל ילד.
- **ביטול החלטה**: ב"טופלו לאחרונה" אפשר להחזיר דיווח או בקשה למצב ממתין.
- העדכונים מגיעים בזמן אמת: דיווח של ילד מופיע אצל המנהל בלי רענון.

## אבטחה
כל החוקים נאכפים בשרת (RLS וטריגרים), לא רק במסך:
- ילד לא יכול לאשר לעצמו דיווח, לשנות קרדיטים או לקנות בלי יתרה.
- ילד לא יכול לקנות כשהחנות סגורה.
- ילד רואה את הבחירות והדיווחים של האחים (בשביל הלוח המשפחתי), אבל רק את בקשות החנות של עצמו.
- משתמשים של אפליקציות אחרות באותו פרויקט לא יכולים לראות כלום. גישה יש רק למי שיש לו פרופיל `ch_profiles`.
